User

This table contains records that identify people. These people may be users that are authorized to access Fluxx, they may be CRM contacts, they may be linked to organizations, requests, grants, reports or each other. The User class includes grantees, users with access to Fluxx, employees and contacts. This class also controls authentication and authorization to the Fluxx application. Note that the password and other relevant columns are on the User class. (The built-in authentication in Fluxx uses a crypted password with a User-specific generated salt. Fluxx also supports various flavors of SAML as well as google authentication.)
