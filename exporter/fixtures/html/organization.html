Organization

This table contains records that identify organizations. Organizations may have users that are authorized to access Fluxx, they may be CRM accounts, they may be linked to users, requests, grants, reports or each other.

Sample List/Search Queries:
* Load up the first page of organization:
  curl --globoff -G 'https://armaninodemo.fluxx.io/api/rest/v2/organization' --data-urlencode '&cols=["name","street_address","street_address2","city","geo_state_id","geo_country_id","postal_code","phone","other_contact","fax"]' --header 'Authorization: Bearer <--token-->'
* Load up the first page of organization using an alternate path:
  curl --globoff -G 'https://armaninodemo.fluxx.io/api/rest/v2/organization/list' --data-urlencode '&cols=["name","street_address","street_address2","city","geo_state_id","geo_country_id","postal_code","phone","other_contact","fax"]' --header 'Authorization: Bearer <--token-->'
* Load up the first page of organization from database:
  curl --globoff -G 'https://armaninodemo.fluxx.io/api/rest/v2/organization' --data-urlencode 'all=1&cols=["name","street_address","street_address2","city","geo_state_id","geo_country_id","postal_code","phone","other_contact","fax"]' --header 'Authorization: Bearer <--token-->'
* Load up the second page of organization:
  curl --globoff -G 'https://armaninodemo.fluxx.io/api/rest/v2/organization' --data-urlencode 'page=2&cols=["name","street_address","street_address2","city","geo_state_id","geo_country_id","postal_code","phone","other_contact","fax"]' --header 'Authorization: Bearer <--token-->'
* Load up the second page of organization from database:
  curl --globoff -G 'https://armaninodemo.fluxx.io/api/rest/v2/organization' --data-urlencode 'all=1&page=2&cols=["name","street_address","street_address2","city","geo_state_id","geo_country_id","postal_code","phone","other_contact","fax"]' --header 'Authorization: Bearer <--token-->'
* Do a full text search for organization:
  curl --globoff -G 'https://armaninodemo.fluxx.io/api/rest/v2/organization' --data-urlencode 'query=search_term&cols=["name","street_address","street_address2","city","geo_state_id","geo_country_id","postal_code","phone","other_contact","fax"]' --header 'Authorization: Bearer <--token-->'
* Do an advanced search using POST instead of GET for organization:
  curl --data 'cols=["name","street_address","street_address2","city","geo_state_id","geo_country_id","postal_code","phone","other_contact","fax"]&filter={"group_type":"or","conditions":[["created_by_id","eq",12810295],["updated_by_id","eq",12810295]]}' -X POST --globoff 'https://armaninodemo.fluxx.io/api/rest/v2/organization/list' --header 'Authorization: Bearer <--token-->'
